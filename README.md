# Paradise Nursery

A dynamic e-commerce shopping cart application for an online plant shop, built with React and Redux Toolkit.

## Features

- Browse houseplants organized into categories
- View plant details: thumbnail, name, and price
- Add plants to a shopping cart
- Dynamically updating cart item count
- Adjust quantities and remove items from the cart
- View total cost per item and overall cart total
- Checkout button (placeholder) and continue shopping navigation

## Tech Stack

- React
- Redux Toolkit
- React-Redux
